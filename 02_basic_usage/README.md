# Basic Usage - Inline Suggestions & Autocomplete

## เป้าหมาย
- เรียนรู้การใช้ Copilot แบบ Inline Suggestions (ghost text)
- ฝึกรับและปัดข้อเสนอด้วย `Tab` และ `Esc`
- **วนดูตัวเลือกอื่นที่ Copilot เสนอ ไม่ใช่รับอันแรกเสมอ**

## สามอย่างที่ต้องได้จาก module นี้

| ทำอะไร | ปุ่ม |
|---|---|
| รับข้อเสนอสีเทา | `Tab` |
| ปัดทิ้ง | `Esc` |
| วนดูตัวเลือกถัดไป / ก่อนหน้า | `Alt` + `]` / `Alt` + `[` |

> 💡 ข้อเสนอแรกไม่ใช่ข้อเสนอเดียว ลองกด `Alt` + `]` ดูสองสามอันก่อนตัดสินใจ
> อย่างน้อยหนึ่งข้อในแบบฝึกหัดข้างล่าง ให้วนดูตัวเลือกทั้งหมดก่อนกด `Tab`

## แบบฝึกหัด

### 1. ฟังก์ชันหาผลรวม
ลองเขียนฟังก์ชันหาผลรวมของตัวเลข 2 ตัว แล้วดู Copilot แนะนำ

### 2. เช็ค Prime Number
เขียนฟังก์ชันเช็คว่าตัวเลขเป็นจำนวนเฉพาะหรือไม่

### 3. การจัดการ Array
ลองสร้าง array และใช้ method ต่างๆ เช่น filter, map, reduce

### 4. String Operations
ทดลองการจัดการ string เช่น การต่อ string, แปลงเป็น uppercase/lowercase

## เทคนิค
- พิมพ์ชื่อฟังก์ชันที่สื่อความหมาย Copilot จะเดาได้ดีขึ้น
- ใช้ชื่อตัวแปรที่มีความหมาย
- เขียน comment อธิบายสิ่งที่ต้องการก่อนเขียนโค้ด
