## Frontend · Snake Game

สร้างเกมงูด้วย HTML + Canvas

**โจทย์**

- งูเคลื่อนที่ในกริด 20×20 ช่อง
- ใช้ปุ่มลูกศร ↑ ↓ ← → คุมทิศทาง
- เกมจบเมื่องูชนตัวเอง หรือชนขอบกริด

**ระบบอาหาร**

- สุ่มวางอาหารบนกริด
- งูกินอาหารแล้ว ยาวขึ้น 1 ช่อง ได้ 10 คะแนน และมีอาหารชิ้นใหม่

**เสร็จเมื่อ**

- [ ] เล่นได้ตามโจทย์ข้างบนครบ
- [ ] แสดงคะแนนระหว่างเล่น
- [ ] กด `P` หยุดชั่วคราว กดอีกครั้งเล่นต่อ
- [ ] กด `Esc` ออกจากเกม
- [ ] อาหารชิ้นใหม่ไม่เกิดทับตัวงู

**ถ้าเหลือเวลา**
ให้งูเร็วขึ้นทุก 50 คะแนน

## Backend · CSV → JSON API

สร้าง API ที่รับไฟล์ CSV แล้วแปลงเป็น JSON

**Endpoints**

| Method | Path | ทำอะไร |
|---|---|---|
| `POST` | `/convert` | upload ไฟล์ CSV แล้วคืน JSON |
| `POST` | `/convert?columns=name,email` | เลือกเฉพาะบาง column |
| `POST` | `/convert?limit=10&offset=0` | แบ่งหน้าข้อมูล |

**เสร็จเมื่อ**

- [ ] แปลง CSV เป็น JSON ได้ถูกต้อง ใช้แถวแรกเป็น header
- [ ] filter `columns` ทำงาน
- [ ] pagination `limit` / `offset` ทำงาน
- [ ] ตอบ error ที่อ่านรู้เรื่อง เมื่อไฟล์ไม่ใช่ CSV หรือเป็นไฟล์ว่าง

> ยิงทดสอบ upload ด้วย curl แบบนี้
> `curl -F "file=@data.csv" "http://localhost:3000/convert?limit=5"`
> ไฟล์ `data.csv` ให้ Copilot สร้างให้ก็ได้

**ถ้าเหลือเวลา**
รองรับค่าที่มี comma อยู่ในเครื่องหมายคำพูด เช่น `"Bangkok, Thailand"`
