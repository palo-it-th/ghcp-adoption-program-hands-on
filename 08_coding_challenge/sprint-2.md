## Frontend · Matching Game

สร้างเกมจับคู่ด้วย HTML, CSS และ JavaScript

**โจทย์**

- การ์ด 16 ใบ เรียงเป็นตาราง 4×4
- มีสัญลักษณ์หรือภาพที่ไม่ซ้ำกัน 8 คู่ สุ่มตำแหน่งแล้ววางคว่ำไว้

**วิธีเล่น**

- คลิกการ์ด การ์ดใบนั้นจะเปิดให้เห็นสัญลักษณ์
- ถ้าสองใบที่เปิดเหมือนกัน ให้เปิดค้างไว้ ถ้าไม่เหมือน ให้คว่ำกลับ

**เสร็จเมื่อ**

- [ ] เกมจบเมื่อจับคู่ครบทุกคู่
- [ ] มีตัวจับเวลาที่นับไปเรื่อย ๆ จนจบเกม
- [ ] มีตัวนับจำนวนครั้งที่เปิด (เปิดสองใบนับเป็น 1 ครั้ง)
- [ ] คลิกใบที่สามระหว่างที่สองใบแรกยังไม่คว่ำกลับ แล้วเกมไม่พัง

**ถ้าเหลือเวลา**
ปุ่มเริ่มใหม่ และเก็บสถิติที่ดีที่สุดไว้ใน `localStorage`

## Backend · JWT Auth

สร้างระบบ Register / Login ด้วย JWT เก็บข้อมูล user ใน memory

**Endpoints**

| Method | Path | ทำอะไร |
|---|---|---|
| `POST` | `/auth/register` | สมัครสมาชิก (`username`, `password`) |
| `POST` | `/auth/login` | เข้าสู่ระบบ คืน JWT token |
| `GET` | `/auth/profile` | ดึงข้อมูล profile ต้องแนบ token |

**เสร็จเมื่อ**

- [ ] password ถูก hash ก่อนเก็บ ใช้ `bcryptjs` ได้ (ถ้า `bcrypt` ติดตั้งไม่ผ่าน)
- [ ] token มีอายุ 1 ชั่วโมง
- [ ] middleware ตรวจ token แล้วตอบ `401` เมื่อไม่มี token หรือ token ไม่ถูกต้อง
- [ ] register ด้วย username ซ้ำไม่ได้

**ถ้าเหลือเวลา**
ถาม Copilot ใน Ask mode ว่าโค้ดของท่านมีช่องโหว่ด้านความปลอดภัยตรงไหน แล้วเช็คว่ามันพูดถูกไหม
